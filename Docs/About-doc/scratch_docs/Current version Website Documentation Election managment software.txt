Client Website – Users Page

1. Overview

The Users page is used to view and manage users/workers registered under the client account. It provides user search, status filtering, user creation, editing, access-key management, and status/permission controls.

2. Page Components

Component

Function

Search Players

Search for a specific user by name/details.

All Status

Filter users based on their current status.

Keys

Opens the user's access-key information.

Add Users

Opens the form to create a new user.

User Table

Displays registered user and assignment details.

3. User Table

Column

Description

Sr.No

User serial number.

Registered user name.

Contact

User contact number.

phoneBook

Phone book status/information.

Prabhaag

Assigned Prabhaag.

Booth

Assigned booth.

SrNo Range

Assigned voter serial-number range.

Status

User's current access status.

Data Import

PDF/Excel import access status.

Created

User creation date and time.

Actions

Edit and Status actions for the user.

4. User Actions

Add Users

Opens the Add User form to create a new user. The form collects User Name, Contact Number, Prabhaag, Booth, and optional SrNo Range.

Flow: Add Users → Enter Details → Add

Edit

Opens the selected user's details for updating their Prabhaag, Booth, and optional SrNo Range. User Name and Contact Number are read-only.

Flow: Edit → Update Assignment → Update

Status

Opens Quick Status Update, where the following can be controlled:

Active Status – Controls whether the user can access the system.

PDF/Excel Import – Controls whether data import is enabled.

Flow: Status → Change Toggles → Update Status

Keys

Opens the user's access-key information:

Unique Key

Reactivation Key

Each key can be copied using the Copy button.

5. Important Dependency

Prabhaag → Booth

A Prabhaag must be selected before a Booth can be selected. The system displays a prompt if the user attempts to select a Booth first.

Function

3. Add Filter

Click + Add Filter to open the Add Filter popup.

Field

Purpose

Filter Type

Select where the value should be added.

Value

Enter the new filter value.

Actions:

Add → Saves the new value.

Cancel → Closes without saving.

The selected category displays its saved values with:

Client Website – Total Voters

Purpose

The Total Voters page is used to view, search, and filter voter records. It provides quick filters for common voter information and advanced filtering for more specific searches.

1. Quick Filters

Each card displays the voter count and Click to Filter option.

Filters: Male • Female • Name Alphabet • Prabhaag • Gan • Electoral Part • Karyakarta • Booth No • Mobile • DOB/Month • Surname • Voted • Non Voted • Visited • Favorites • Helped • Address • Outside • Printed • Deceased • House No • Schemes

Action: Click to Filter → Apply Filter → Voter List Updates

2. Search Voters

Search voters... allows users to quickly search for a specific voter from the available records.

3. Advanced Filters

The Advanced Filters → More Filters option provides additional conditions for detailed voter searches.

Users can combine multiple conditions to narrow the voter list and get more specific results.

Typical filtering areas include:

Personal Details: Name, Surname, Gender, Age/DOB

Location: Prabhaag, Gan, Part, Booth, House No, Address

Contact: Mobile availability

Work/Category: Karyakarta, Occupation, Caste, Qualification

Voting: Voted, Non Voted, Visited

Status: Printed, Outside, Deceased, Favourite, Helped

Schemes: Government scheme

Flow: More Filters → Select Conditions → Apply → Filtered Voters

4. Voter Results

Filtered voters are displayed with:

ID • Voter Name • Age • Gender • EPIC • Mobile • Booth No • Karyakarta • Actions

Actions:

Refresh → Reload voter data

Send SMS → Send SMS to applicable voters

Export → Export voter data

View → Open complete voter details

5. Voter Details

View → Voter Details opens the selected voter's complete information, including personal, address, booth, voting, and other available details.

6. Filter Flow

Quick Filter / Search / Advanced Filter → Apply → View Results → View Voter Details

Client Website – Export Voter Data

Purpose

The Export Voter Data page allows the user to select a worker, view the voters handled by that worker, and export their voter data.

1. Select Worker

Select a worker from the dropdown to load the voters associated with that worker.

Displayed: Worker Name • Contact Number • Voter Count

2. Search Voters

Search by Name, EPIC, or Mobile allows the user to quickly find a specific voter from the selected worker's records.

Refresh reloads the voter list.

3. Voters List

After selecting a worker, the page displays the Voters List containing all voters worked on by that worker.

If no records are available, the page displays: “This worker has not worked on any voters yet.”

4. Export

The page is designed to allow the selected worker's voter records to be exported to Excel.

The exported file contains the available voter information.

5. Instructions

Select a worker.

View the worker's voter records.

Search if required.

Export the voter data to Excel.

Flow

Select Worker → View/Search Voters → Export to Excel

Client Website – Phone Book

Purpose

The Phone Book page shows voters who are assigned to a selected worker and have phone-book information available.

1. Select Worker

Use Select Worker to choose a worker and view their assigned phone-book voters.

Displayed: Worker Name • Contact Number • Voter Count

2. Search

Search by Name, Voter ID, or Mobile helps quickly find a specific voter.

Refresh reloads the phone-book data.

3. Export Excel

Export Excel downloads the available phone-book voter data in Excel format.

4. PhoneBook Voters

Displays the total number of phone-book voters assigned to the selected worker.

If no records are available, the page shows:

“No phonebook voters assigned to this worker.”

Flow

Select Worker → View PhoneBook Voters → Search → Export Excel

Admin Panel – Add New User

Purpose

The Add User button opens the Add New User form. It is used to create a new client/user account and configure its election and application details.

1. Account Details

Admin Username* – Username for the new account.

Contact Number* – 10-digit contact number.

Password* – Account login password.

2. Election & Application Details

Election Type* – Select the election.

Sub-Part – Select the sub-part based on the selected election.

Name/Area – Select the applicable area.

Name (English/Marathi)* – Enter the area/name in both languages.

Election Name (English/Marathi)* – Enter the election name.

Application Name* – Name of the application.

Party Name (English/Marathi)* – Enter the party name.

Voting Symbol* – Enter the voting symbol in English and Marathi.

Dependency: Election → Sub-Part → Name/Area

3. Additional Details

WhatsApp Number – Account WhatsApp contact.

Facebook Link – Facebook page/profile link.

Instagram Link – Instagram link.

Slip URL – Optional slip/document URL.

Theme* – Select application theme.

Support Number – Support contact number.

Account Type* – Select Demo (Trial) or Sale (Permanent) account.

Election Project* – Select the project used for the application/APK.
