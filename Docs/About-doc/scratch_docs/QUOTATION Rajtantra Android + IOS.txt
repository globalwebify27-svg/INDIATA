Project Overview

Global Webify proposes to design, develop, and deploy RajTantra, a modern Political Campaign & Voter Management Platform specially designed for Political Parties, Election Candidates, MLAs, MPs, Corporators, Ward Councillors (Ward Parshads), Campaign Managers, and Election Workers.

The platform will streamline election management by providing a centralized system for voter database management, campaign execution, worker management, advertisement distribution, and real-time voter updates.

The solution consists of:

Flutter Mobile Application (Android & iOS) – Only for End Users (Ward Parshads / Workers / Contesting Members)

Next.js Web Admin Panel – Role-Based Access

Node.js Backend APIs

MySQL Database

The platform is designed to be secure, scalable, and capable of handling large voter databases across multiple districts and constituencies.
